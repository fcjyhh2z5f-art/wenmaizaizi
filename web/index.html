本页所有功能均在本机执行：没有服务器地址、没有访问令牌、没有任何 fetch 请求。飞行模式下照常检索与导入。
三种形态
  1. iOS 原生 App：云构建出未签名 IPA → 爱思助手用 Apple ID 签名 → 数据线装进 iPhone。免费签 7 天，到期重签即可，书库数据不丢。
  2. 安卓 APK：云编译出 debug 签名 APK，直接装进华为 / vivo / 小米等手机，在系统里允许「安装未知应用」即可；不需要 Mac、不需要开发者账号、不需要 7 天重签。
  3. PWA 兜底：用 HTTPS 地址首次打开后「分享 → 添加到主屏幕」，页面由 Service Worker 缓存；局域网 HTTP 下不会缓存，别用电脑直连地址。
签名请用专用 Apple ID 小号，不要交主力账号密码。详细步骤与错误码见随程序附带的 README。
独立性说明
  • 检索引擎：offline-engine.js，纯 JavaScript，与电脑版 engine.py 语义一致。
  • 书库与设置：存本机 IndexedDB（不可用时降级 localStorage），可随时导出 JSON 快照。
  • 简繁异体对照表随程序分发，运行时不依赖任何在线服务或转换库。
  • 不读取 WorkBuddy 技能目录、不调用技能脚本、不需要电脑开机；iOS 与安卓版共用同一套 web 代码与图标。
